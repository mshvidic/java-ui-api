# Java UI API Automation Framework

A test automation repository structured for integrating UI and API validation layers using Java.

## 🚀 Project Overview

This project is designed to test and validate software applications across multiple layers, combining backend API assertions with frontend UI automation.

## 🛠️ Tech Stack

* **Language:** Java
* **Build Tool:** Maven (`pom.xml`)
* **Testing Scope:** UI Automation & API Integration

## 📁 Repository Structure

* `src/test/java` - Contains test classes and automation scripts.
* `drivers` - Browser drivers or local binaries.
* `documents` - Project documentation, requirements, or test artifacts.
* `.settings` / `.project` / `.classpath` - IDE configuration files (Eclipse/IDE-specific).
* `pom.xml` - Maven configuration and project dependencies.

## ⚙️ Prerequisites

Ensure you have the following installed on your machine:
* Java Development Kit (JDK 11 or higher)
* Maven
